# Photo editing

Choose photo and Take photo stage a local file, then open the same full-screen editor. Edit photo opens an existing cover without modifying it. Leaving the editor cancels that photo operation; newly imported/captured staging copies are removed, while existing covers are retained.

The editor offers a free-aspect crop with draggable corners/edges and a movable interior. Precise crop controls expose horizontal/vertical range sliders as an alternative to gestures. Brightness (-50 to +50 percent offset) and contrast (50–200 percent) preview using the same color matrix used for output. Rotate turns clockwise in 90-degree steps and resets the crop to the full rotated image; brightness/contrast remain. Reset restores the original orientation, full crop and neutral adjustments. Crop/adjustment/rotation state and the staged filename survive saved-state restoration. Buttons respect Android system insets and saving disables duplicate actions.

Images are decoded locally with a power-of-two sample size, a maximum 2560-pixel edge for export and 1280 pixels for preview. EXIF rotation/mirroring is applied before editing. Input is limited to 20 MiB and sane dimensions. Crop coordinates are fractions of the upright, manually rotated image, so different preview/output resolutions do not change the selected region. Exports crop and flatten to a white-backed JPEG, apply the color matrix, synchronize file bytes and verify the encoded dimensions before acceptance. Exported images have upright pixels and no inherited GPS/EXIF metadata. The original gallery file, imported/camera source and any current saved cover are never overwritten. A failed export deletes its output and leaves the editor available for retry. Temporary imported/camera sources are removed only on acceptance or explicit cancellation; an interrupted process can leave an unreferenced staging file. Older cover photos are retained for recovery revisions, as elsewhere in Hodd.

Use photo replaces only the current form's draft cover and immediately offers Find details from this photo. Not now keeps the edited photo and continues manual entry. Identify photo reads the edited image locally, then opens the existing suggestion/identity review. An online catalog request requires Find catalog matches on the reviewed identity; the photo is not uploaded. Applying suggestions still needs confirmation, and catalog changes still require Save on the item form. Unsupported collectible types can be recognized locally but have no online provider.

Verification covers normalized crop bounds, pixel dimensions/color adjustments, EXIF orientation/mirroring, bounded decode, invalid/in-place output rejection, edit/rotate/reset/cancel, saved-state restoration, gallery/camera result routing and acceptance followed by identification. Camera/picker tests inject activity results on a disposable emulator; physical camera/picker behavior and image quality still need phone testing. These tests never launch a real camera or access a personal gallery.
